## Installation

Clone the repository

```bash
git clone https://github.com/yashvskothari/portfolio.git
```

Navigate into the project

```bash
cd portfolio
```

Open the project using VS Code and run it using Live Server.

No additional installation or build process is required.

## Contact Form

The contact form is powered by EmailJS.

To use it:

1. Create an EmailJS account.
2. Connect your email service.
3. Create an email template.
4. Replace the following values inside `script.js`:

```
PUBLIC_KEY
SERVICE_ID
TEMPLATE_ID
```
